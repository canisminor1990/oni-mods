# Thermal Info Cards

Shows thermal conductivity, thermal mass, heat energy, and phase-change temperatures on hover and in the build menu. Hover cards can stack matching objects and sum thermal mass and heat energy. Peter Han's [Thermal Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=1983504552) and Aze's [Better Info Cards](https://steamcommunity.com/sharedfiles/filedetails/?id=1960947963) conflict when both are enabled; this remake exists to combine both features so you do not need either original or PLib.

### Languages

UI text covers English, Chinese, Japanese, and Korean.

![Languages](https://raw.githubusercontent.com/canisminor1990/oni-mods/refs/heads/master/i18n.png)

### Features

- Hovering a building, debris, or tile shows temperature, thermal conductivity, thermal mass, and heat energy.
- Matching hover cards stack; titles, germs, ore mass, temperature, thermal mass, and heat energy are summed or averaged.
- Click cycles through stacked cards. Shift+click cycles objects inside a stack.
- Phase changes list the result (and any secondary ore) at the real transition temperature, including the 3 °C hysteresis.
- The build menu material pane shows the finished building's conductivity, thermal mass, and melting point for the selected material.
- Insulated tiles and non-solid buildings use the same mass and conductivity rules as the game's heat simulation.

### Settings

- Open the Mods list, then click Settings on this mod.
- **Display All Units**: show Celsius, Fahrenheit, and Kelvin together. The game's preferred unit is listed first.
- **Only on Thermal Overlay**: extra stats appear only on the Temperature Overlay. Temperature itself still shows in the default view.
- **Hide Element Categories**, **Restrict Selections**, **First Selection Hover**, and **Compact Cards** control the stacked hover cards.
- Thermal lines apply immediately. Card size and some overlay tweaks may need a restart.

### Notes

- Please do not enable this together with the original [Thermal Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=1983504552) or [Better Info Cards](https://steamcommunity.com/sharedfiles/filedetails/?id=1960947963).
- Display All Temps keeps control of the temperature string if that mod is present.

# 热量信息卡 / Thermal Info Cards

*原版 [Thermal Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=1983504552) 与 [Better Info Cards](https://steamcommunity.com/sharedfiles/filedetails/?id=1960947963) 互相冲突、无法同时启用。本模组把两者合并，在悬浮提示和建造菜单里显示热导率、热容、热量和相变温度；相同物体的卡片会合并并合计热容/热量。用语按[计量单位 · 热量](https://oxygennotincluded.wiki.gg/zh/wiki/%E8%AE%A1%E9%87%8F%E5%8D%95%E4%BD%8D#%E7%83%AD%E9%87%8F)。独立制作，无需原版或 PLib。*

### 语言

界面文本覆盖英语、中文、日语和韩语。

![Languages](https://raw.githubusercontent.com/canisminor1990/oni-mods/refs/heads/master/i18n.png)

### 功能

- 悬停建筑、掉落物或地格时，显示温度、热导率、热容和热量。
- 相同悬浮卡片会叠在一起；名称、病菌、矿石质量、温度、热容和热量会合计或取平均。
- 点击在叠卡之间切换。按住 Shift 再点可在同一叠里的物体之间切换。
- 相变会列出产物（以及次要矿石）和实际转变温度，已计入 3 °C 滞后。
- 建造菜单的材料面板会显示完工后的热导率、热容和熔点。
- 隔热砖和非实体建筑使用与游戏热模拟相同的质量与热导规则。

### 设置

- 打开模组列表，点击本模组的「设置」。
- **显示全部温度单位**：同时显示摄氏度、华氏度和开尔文（绝对温标），游戏首选单位排在最前。
- **仅在温度视图下显示**：热导率、热容和热量只在温度视图出现。默认视图仍显示温度。
- **隐藏元素类别**、**限制选择范围**、**首次选择指向对象**、**紧凑卡片** 控制叠卡行为。
- 热量行立即生效。卡片尺寸和部分视图改动可能需要重启。

### 说明

- 请勿与原版 [Thermal Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=1983504552) 或 [Better Info Cards](https://steamcommunity.com/sharedfiles/filedetails/?id=1960947963) 同时启用。
- 若装了 Display All Temps，温度字符串仍由它控制。

[h1]Mod List Previews[/h1]

Shows Steam Workshop cover thumbnails in the in-game Mods list. Local and Dev mods use [i]preview.png[/i] / [i]preview.jpg[/i] if present.

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]Features[/h3]

[list]
[*]Adds a cover thumbnail on the left of each row. A placeholder is shown when no image is available.
[*]Uses Steam's already-downloaded preview, then the local cache, then a Workshop fetch.
[*]Local and Dev mods read [i]preview.png[/i] / [i]preview.jpg[/i] from the mod folder.
[*]Failed downloads are retried the next time the list opens or the game launches.
[*]Compatible with Mod Profile Manager (MPM) pin and tag buttons.
[/list]

[h3]Recommended[/h3]

Optional. This mod runs on its own.

[list]
[*][url=https://steamcommunity.com/workshop/filedetails/?id=2018291283]Mod Updater[/url]
[*][url=https://steamcommunity.com/workshop/filedetails/?id=2854869130]Mod Profile Manager (MPM)[/url]
[/list]

[h3]Settings[/h3]

[list]
[*]Open the Mods list, then click Settings on this mod.
[*]Cover size: 32–128 px, default 56.
[*]Refresh covers clears the local cache and downloads again.
[/list]

Fully quit the game after enabling or updating this mod. Covers may take a second or two to appear the first time the list opens. Cache path: [i]Documents/Klei/OxygenNotIncluded/mods/config/ModListPreviews/[/i].

[h1]模组封面预览 / Mod List Previews[/h1]

[i]在游戏内模组列表中显示创意工坊封面。本地和 Dev 模组如果有 preview.png 也会显示。[/i]

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]功能[/h3]

[list]
[*]在每一行左侧显示封面。没有图片时显示占位图。
[*]优先使用 Steam 已下载的预览图，其次是本地缓存，最后向创意工坊获取。
[*]本地和 Dev 模组会读取目录中的 [i]preview.png[/i] / [i]preview.jpg[/i]。
[*]下载失败时，下次打开列表或下次启动游戏会重试。
[*]与 Mod Profile Manager (MPM) 的钉选和标签按钮兼容。
[/list]

[h3]设置[/h3]

[list]
[*]打开模组列表，点击本模组的「设置」。
[*]封面尺寸：32–128 像素，默认 56。
[*]「刷新封面」会清除本地缓存并重新下载。
[/list]

启用或更新本模组后，请完全退出游戏再启动。第一次打开列表时，封面可能晚一两秒出现。缓存目录：[i]Documents/Klei/OxygenNotIncluded/mods/config/ModListPreviews/[/i]。

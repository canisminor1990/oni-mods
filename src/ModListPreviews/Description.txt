[h1]Mod List Previews[/h1]

Shows Steam Workshop cover thumbnails in the in-game Mods list.

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]Features[/h3]

[list]
[*]Adds a cover thumbnail on the left of each Mods list row. A placeholder is shown when no image is available.
[*]Covers come from Steam's already-downloaded preview, then the local cache, then a Workshop fetch.
[*]Local and Dev mods also use [i]preview.png[/i] / [i]preview.jpg[/i] in the mod folder if present.
[*]Covers that fail due to network errors are retried the next time the list opens or the game launches.
[*]Compatible with Mod Profile Manager pin / tag buttons.
[*]No new buildings, resources, recipes, or balance changes.
[/list]

[h3]Recommended[/h3]

Optional. This mod runs on its own.

[list]
[*][url=https://steamcommunity.com/workshop/filedetails/?id=2018291283]Mod Updater[/url]
[*][url=https://steamcommunity.com/workshop/filedetails/?id=2854869130]Mod Profile Manager (MPM)[/url]
[/list]

[h3]Settings[/h3]

[list]
[*]Open the Mods list from the main menu or pause menu, then click Settings on this mod's row.
[*]Cover size: 32–128 px, default 56.
[*]Refresh covers clears the local cache and downloads Workshop images again.
[/list]

[h3]Notes[/h3]

[list]
[*]Fully quit and relaunch the game after enabling or updating this mod.
[*]Chinese and English UI.
[*]Cover cache is stored at [i]Documents/Klei/OxygenNotIncluded/mods/config/ModListPreviews/[/i].
[*]Covers may appear a second or two after the list first opens.
[/list]

[h1]模组封面预览 / Mod List Previews[/h1]

[i]在游戏内模组列表显示创意工坊封面缩略图。本地 / Dev 模组如果有 preview.png 也会显示。[/i]

这是一个 Oxygen Not Included 模组管理界面便利模组。

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]功能[/h3]

[list]
[*]在模组列表每一行左侧显示创意工坊封面。没有封面时显示占位图。
[*]封面优先用 Steam 已下载的预览图，其次用本地缓存，再向创意工坊拉取。
[*]本地模组和 Dev 模组会读取目录里的 [i]preview.png[/i] / [i]preview.jpg[/i]。
[*]网络失败的封面会记下来，下次打开列表或下次启动时自动重试。
[*]与 Mod Profile Manager 的钉选 / 标签按钮并存。
[*]不新增建筑、不新增资源、不改配方、不改变游戏平衡。
[/list]

[h3]建议订阅[/h3]

可选。本模组可以单独运行。

[list]
[*][url=https://steamcommunity.com/workshop/filedetails/?id=2018291283]Mod Updater[/url]
[*][url=https://steamcommunity.com/workshop/filedetails/?id=2854869130]Mod Profile Manager (MPM)[/url]
[/list]

[h3]设置[/h3]

[list]
[*]主菜单或暂停菜单打开模组列表，在本模组那一行点「设置」。
[*]封面尺寸：32–128 像素，默认 56。
[*]「刷新封面」会清除本地缓存并重新下载。
[/list]

[h3]说明[/h3]

[list]
[*]启用或更新本模组后，需要完全退出游戏再启动。
[*]界面提供中文 / English。
[*]封面缓存写在 [i]Documents/Klei/OxygenNotIncluded/mods/config/ModListPreviews/[/i]。
[*]第一次打开列表时，封面可能会隔一两秒陆续出现。
[/list]

# Mod List Previews

Shows Steam Workshop cover thumbnails in the in-game Mods list. Local and Dev mods use `preview.png` / `preview.jpg` if present.

![ALL DLC](https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png)

Steam Workshop: [Mod List Previews](https://steamcommunity.com/sharedfiles/filedetails/?id=3794018361) · [Description.txt](Description.txt) (BBCode)

### Features

- Adds a cover thumbnail on the left of each row. A placeholder is shown when no image is available.
- Uses Steam's already-downloaded preview, then the local cache, then a Workshop fetch.
- Local and Dev mods read `preview.png` / `preview.jpg` from the mod folder.
- Failed downloads are retried the next time the list opens or the game launches.
- Compatible with Mod Profile Manager (MPM) pin and tag buttons.

### Recommended

Optional. This mod runs on its own.

- [Mod Updater](https://steamcommunity.com/workshop/filedetails/?id=2018291283)
- [Mod Profile Manager (MPM)](https://steamcommunity.com/workshop/filedetails/?id=2854869130)

### Settings

- Open the Mods list, then click Settings on this mod.
- Cover size: 32–128 px, default 56.
- Refresh covers clears the local cache and downloads again.

Fully quit the game after enabling or updating this mod. Covers may take a second or two to appear the first time the list opens. Cache path: `Documents/Klei/OxygenNotIncluded/mods/config/ModListPreviews/`.

# 模组封面预览 / Mod List Previews

*在游戏内模组列表中显示创意工坊封面。本地和 Dev 模组如果有 preview.png 也会显示。*

![ALL DLC](https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png)

### 功能

- 在每一行左侧显示封面。没有图片时显示占位图。
- 优先使用 Steam 已下载的预览图，其次是本地缓存，最后向创意工坊获取。
- 本地和 Dev 模组会读取目录中的 `preview.png` / `preview.jpg`。
- 下载失败时，下次打开列表或下次启动游戏会重试。
- 与 Mod Profile Manager (MPM) 的钉选和标签按钮兼容。

### 建议订阅

可选。本模组可以单独使用。

- [Mod Updater](https://steamcommunity.com/workshop/filedetails/?id=2018291283)
- [Mod Profile Manager (MPM)](https://steamcommunity.com/workshop/filedetails/?id=2854869130)

### 设置

- 打开模组列表，点击本模组的「设置」。
- 封面尺寸：32–128 像素，默认 56。
- 「刷新封面」会清除本地缓存并重新下载。

启用或更新本模组后，请完全退出游戏再启动。第一次打开列表时，封面可能晚一两秒出现。缓存目录：`Documents/Klei/OxygenNotIncluded/mods/config/ModListPreviews/`。

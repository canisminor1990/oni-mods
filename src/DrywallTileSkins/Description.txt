[h1]Drywall Tile Skins[/h1]

Turns loaded tile textures into blueprint skins for vanilla Drywall. Only the interior cell is repeated, without tile borders.

This is only a cosmetic mod, gameplay is unaffected.

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]Features[/h3]

[list]
[*]No new building. Skins use vanilla Drywall and the built-in blueprint picker.
[*]Repeats the tile interior only and hides 9-slice borders.
[*]Imports currently loaded tile textures, including vanilla, DLC, and True Tiles packs.
[*]Includes a set of cartoon prints: Pastel Dots, Citrus Slices, Colony Stars, Mushroom Caps, Raindrops, Puffy Clouds, Scattered Leaves, Honeycomb, Wavy Sea, Candy Hearts, Cartoon Bricks, Plus Grid, Little Fish, Tiny Flowers, Aqua Bubbles, Soft Checkers, Little Suns, Candy Diamonds.
[*]Decor Pack stained-glass tiles are merged into one group.
[*]Blueprint inventory is grouped by tile type.
[/list]

[h3]Settings[/h3]

[list]
[*]Open the Mods list, then click Settings on this mod.
[*]Enable or disable wallpaper groups by tile type. Disabled groups are not registered as blueprints.
[*]Fully restart the game after changing settings or adding custom PNGs.
[/list]

The number of skins depends on which tile mods you have enabled. If the list is too long, turn unused groups off in Settings.

[h1]干板墙瓷砖皮肤 / Drywall Tile Skins[/h1]

[i]把已加载的瓷砖纹理做成原版干板墙的蓝图皮肤。只重复中间格，没有砖缝。[/i]

仅装饰，不影响玩法。不新增建筑。

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]功能[/h3]

[list]
[*]皮肤挂在原版干板墙上，使用游戏自带的蓝图选择器。
[*]只重复瓷砖中间格，并隐藏九宫格边框。
[*]自动导入当前已加载的瓷砖纹理，包括原版、DLC 和 True Tiles。
[*]自带一批卡通墙纸：奶油波点、柠檬片、星空、蘑菇点、雨滴、云朵、绿叶、蜂巢、海浪、爱心、卡通砖、十字格、小鱼、小花、气泡、软格子、小太阳、菱形糖。
[*]Decor Pack 的琉璃砖合并为一组。
[*]蓝图库存按砖块类型分组。
[/list]

可选。本模组可以单独使用。

[h3]自定义贴图[/h3]

[list]
[*]把正方形 PNG 放到 [i]Documents/Klei/OxygenNotIncluded/mods/config/DrywallTileSkins/custom_walls/[/i]
[*]同时扫描 Backwalls 的自定义目录：[i]mods/config/backwalls/custom_walls/[/i]
[*]可选同名 [i]文件名.metadata.json[/i]：
[/list]

[code]{ "Name": "显示名称" }[/code]

[h3]设置[/h3]

[list]
[*]打开模组列表，点击本模组的「设置」。
[*]可按类型启用或关闭墙纸组。关闭的组不会生成蓝图。
[*]修改设置或增减自定义 PNG 后，需要完全重启游戏。
[/list]

皮肤数量取决于你启用了哪些瓷砖模组。列表过长时，可在设置中关闭不需要的分组。

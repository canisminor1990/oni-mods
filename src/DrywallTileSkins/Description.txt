[h1]Drywall Tile Skins[/h1]

Drywall Tile Skins turns loaded tile textures into blueprint skins for vanilla Drywall.

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]Features[/h3]
[list]
[*]No new building. Skins hang on vanilla Drywall and use the built-in blueprint picker.
[*]Repeats the tile interior cell only and hides 9-slice caps, so the wall reads as wallpaper instead of tiled bricks.
[*]Imports currently loaded tile textures, including vanilla, DLC, and True Tiles packs.
[*]Includes a set of cartoon prints: Pastel Dots, Citrus Slices, Colony Stars, Mushroom Caps, Raindrops, Puffy Clouds, Scattered Leaves, Honeycomb, Wavy Sea, Candy Hearts, Cartoon Bricks, Plus Grid, Little Fish, Tiny Flowers, Aqua Bubbles, Soft Checkers, Little Suns, Candy Diamonds.
[*]Decor Pack stained-glass tiles are merged into one group so the picker is not flooded with near-identical prints.
[*]Blueprint inventory is grouped by tile type.
[/list]

[h3]Custom prints[/h3]
[list]
[*]Drop square PNG files into [i]Documents/Klei/OxygenNotIncluded/mods/config/drywall_tile_skins/custom_walls/[/i]
[*]Backwalls custom folder is also scanned: [i]mods/config/backwalls/custom_walls/[/i]
[*]Optional sidecar [i]filename.metadata.json[/i]:
[/list]
[code]{ "Name": "Display Name" }[/code]

[h3]Settings[/h3]
[list]
[*]Open the Mods list from the main menu or pause menu, then click Settings on this mod's row.
[*]Enable or disable wallpaper groups by tile type. Disabled groups are not registered as blueprints.
[*]Fully restart the game after changing settings or adding custom PNGs.
[/list]

[h3]Notes[/h3]
[list]
[*]No new buildings, resources, recipes, or balance changes.
[*]Chinese and English UI.
[*]The number of skins depends on which tile mods and texture packs you have enabled. If the list is too long, turn unused groups off in Settings.
[/list]

[h1]干板墙瓷砖皮肤 / Drywall Tile Skins[/h1]

[i]把已加载的瓷砖纹理做成原版干板墙蓝图皮肤。铺上去只重复中间格花纹，没有瓷砖边框。[/i]

这是一个 Oxygen Not Included 装饰用干板墙皮肤模组。

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]功能[/h3]
[list]
[*]不新增建筑。皮肤挂在原版干板墙上，用游戏自带的蓝图选择器切换。
[*]墙面按瓷砖中间格重复铺贴，会藏掉九宫格边框，看起来像一整面墙纸。
[*]自动收录当前存档里已加载的瓷砖纹理，包括原版、DLC，以及 True Tiles 材质包。
[*]自带一批卡通墙纸：奶油波点、柠檬片、星空、蘑菇点、雨滴、云朵、绿叶、蜂巢、海浪、爱心、卡通砖、十字格、小鱼、小花、气泡、软格子、小太阳、菱形糖。
[*]Decor Pack 琉璃砖会合并成同一组，避免蓝图列表被同款花纹刷屏。
[*]蓝图库存按砖块类型分组，方便查找。
[/list]

[h3]自定义贴图[/h3]
[list]
[*]把正方形 PNG 放到 [i]Documents/Klei/OxygenNotIncluded/mods/config/drywall_tile_skins/custom_walls/[/i]
[*]也兼容 Backwalls 的自定义目录：[i]mods/config/backwalls/custom_walls/[/i]
[*]可选同名 [i]文件名.metadata.json[/i]，格式：
[/list]
[code]{ "Name": "显示名称" }[/code]

[h3]设置[/h3]
[list]
[*]主菜单或暂停菜单打开模组列表，在本模组那一行点「设置」。
[*]可按类型勾选要加载的墙纸。取消勾选后对应贴图不会生成蓝图。
[*]修改设置或增减自定义 PNG 后，需要完全重启游戏才生效。
[/list]

[h3]说明[/h3]
[list]
[*]本模组不新增建筑、不新增资源、不改配方、不改变游戏平衡。
[*]界面提供中文 / English。
[*]皮肤数量取决于你启用了哪些瓷砖模组和材质包。砖块种类很多时，可在设置里关掉不需要的分组。
[/list]

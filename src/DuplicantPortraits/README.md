# Duplicant Portraits

Adds a masterpiece painting of every loaded duplicant personality to the vanilla 2x2 Blank Canvas.

![ALL DLC](https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png)

Steam Workshop description (BBCode): [Description.txt](Description.txt)

### Features

- No new building. Portraits hang on the smallest vanilla canvas.
- One Looking Great artwork per personality, using that duplicant's headshot.
- After an artist finishes a masterpiece, pick the portrait with the vanilla artwork selector.
- Includes personalities from subscribed DLCs.

### How to use

1. Build a Blank Canvas.
2. Have a duplicant with Masterworks decorate it.
3. Select the painting and choose "Portrait of {Name}".

### Notes

- Decor matches vanilla masterpiece paintings.
- Chinese and English UI.
- Headshots come from the built-in personality portraits, not a live photo of colony outfits.

# 复制人头像画 / Duplicant Portraits

*给原版 2x2 空白画布加上每个复制人性格的杰作肖像画。*

这是一个 Oxygen Not Included 装饰画模组。

![ALL DLC](https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png)

### 功能

- 不新增建筑。肖像挂在原版最小的装饰画（空白画布，2x2）上。
- 为当前已加载的每个复制人性格生成一幅杰作级画作，画框里是该小人的头像。
- 由艺术家画成杰作之后，用原版的选画界面切换想挂的头像。
- 包含当前启用的 DLC 性格。未订阅的 DLC 性格不会出现。

### 用法

1. 建造空白画布。
2. 让有「杰作」技能的复制人完成装饰。
3. 选中画作，点选画按钮，挑选「某某的肖像」。

### 说明

- 装饰值和原版杰作画相同。
- 界面提供中文 / English。
- 头像来自游戏自带的小人肖像，不是实时拍照；服装染色不会反映在画上。

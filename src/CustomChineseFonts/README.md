# Custom Chinese Fonts

Custom Simplified Chinese UI fonts for Oxygen Not Included. Body text defaults to HarmonyOS Sans SC; titles can be switched in Settings, and you can drop in your own fonts. This mod uses HarmonyOS Sans Fonts.

![ALL DLC](https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png)

Steam Workshop description (BBCode): [Description.txt](Description.txt)

### Features

- Chinese body text uses HarmonyOS Sans SC Regular by default.
- Chinese titles default to HarmonyOS Sans SC Bold; Jinzishe Dezheng and your own font are optional in Settings.
- English fonts are left unchanged by default. Enable English replacement in Settings to swap GRAYSTROKE / Roboto.

### Settings

- Open the Mods list from the main menu or pause menu, then click Settings on this mod's row.
- After turning English replacement off, fully restart the game to restore vanilla English fonts.

### Your own fonts

- Put a TTF or OTF in `Documents/Klei/OxygenNotIncluded/mods/config/CustomChineseFonts/custom_fonts/`
- `body.ttf` or `body.otf` replaces Chinese body text
- `title.ttf` or `title.otf` adds a Custom title option in Settings
- The folder (and a `README.txt`) is created the first time the mod loads
- Fully quit the game after adding or replacing fonts
- You must have the right to use the font. Missing glyphs fall back to HarmonyOS Sans SC

# 自定义中文字体 / Custom Chinese Fonts

*自定义缺氧游戏里的中文界面字体。正文默认 HarmonyOS Sans SC，标题可在设置里切换，也可以放进自己的字体。本模组使用 HarmonyOS Sans Fonts。*

这是一个 Oxygen Not Included 中文界面字体模组。

![ALL DLC](https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png)

### 功能

- 中文**正文**默认使用 HarmonyOS Sans SC Regular。
- 中文**标题**默认 HarmonyOS Sans SC Bold，可在设置里改成金字社得正体，或你自己的字体。
- **英文字体**默认不替换；可在设置里打开，用当前正文字体 / 标题字体替换 GRAYSTROKE / Roboto。

### 设置

- 主菜单或暂停菜单打开模组列表，在本模组那一行点「设置」。
- 关闭英文替换后，需要完全重启游戏才会恢复原版英文字体。

### 用自己的字体

- 把 TTF 或 OTF 放到 `Documents/Klei/OxygenNotIncluded/mods/config/CustomChineseFonts/custom_fonts/`
- `body.ttf` 或 `body.otf`：替换中文正文
- `title.ttf` 或 `title.otf`：出现在设置里的「自定义」标题选项
- 第一次启动模组后，这个文件夹会自动创建，里面有一份 `README.txt`
- 放好或更换字体后，必须**完全退出游戏再进**（热重载无效）
- 请确保你有权使用该字体。缺字时会回退到鸿蒙黑体

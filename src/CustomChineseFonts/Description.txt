[h1]Custom Chinese Fonts[/h1]

Replaces the Simplified Chinese UI fonts. Body text defaults to HarmonyOS Sans SC; titles can be changed in Settings. You can also add your own TTF/OTF.

This mod uses HarmonyOS Sans Fonts.

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]Features[/h3]

[list]
[*]Chinese body text uses HarmonyOS Sans SC Regular.
[*]Chinese titles default to HarmonyOS Sans SC Bold. Jinzishe Dezheng and a custom file are optional in Settings.
[*]English fonts are unchanged unless you enable replacement in Settings (GRAYSTROKE / Roboto).
[/list]

[h3]Settings[/h3]

[list]
[*]Open the Mods list, then click Settings on this mod.
[*]After turning English replacement off, fully quit the game to restore vanilla English fonts.
[/list]

[h3]Your own fonts[/h3]

[list]
[*]Put a TTF or OTF in [i]Documents/Klei/OxygenNotIncluded/mods/config/CustomChineseFonts/custom_fonts/[/i]
[*][i]body.ttf[/i] / [i]body.otf[/i] replaces Chinese body text
[*][i]title.ttf[/i] / [i]title.otf[/i] adds a Custom option in the title list
[*]The folder (and a [i]README.txt[/i]) is created the first time the mod loads
[*]Fully quit the game after adding or replacing fonts
[*]Missing glyphs fall back to HarmonyOS Sans SC. You must have the right to use the font.
[/list]

[h1]自定义中文字体 / Custom Chinese Fonts[/h1]

[i]替换游戏的简体中文界面字体。正文默认鸿蒙黑体，标题可在设置里更换。本模组使用 HarmonyOS Sans Fonts。[/i]

也可以放入自己的 TTF / OTF。

[img]https://raw.githubusercontent.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/refs/heads/master/Compat_All.png[/img]

[h3]功能[/h3]

[list]
[*]中文正文默认 HarmonyOS Sans SC Regular。
[*]中文标题默认 HarmonyOS Sans SC Bold。设置里可选金字社得正体，或自己的字体。
[*]英文字体默认不替换。在设置里打开后，才会替换 GRAYSTROKE / Roboto。
[/list]

[h3]设置[/h3]

[list]
[*]打开模组列表，点击本模组的「设置」。
[*]关闭英文替换后，需要完全退出游戏，英文字体才会恢复。
[/list]

[h3]用自己的字体[/h3]

[list]
[*]把 TTF 或 OTF 放到 [i]Documents/Klei/OxygenNotIncluded/mods/config/CustomChineseFonts/custom_fonts/[/i]
[*][i]body.ttf[/i] / [i]body.otf[/i]：替换中文正文
[*][i]title.ttf[/i] / [i]title.otf[/i]：标题列表中的「自定义」选项
[*]第一次加载模组时会自动创建文件夹，内含 [i]README.txt[/i]
[*]添加或更换字体后，请完全退出游戏
[*]缺字时回退到鸿蒙黑体。请确保你有权使用该字体。
[/list]
